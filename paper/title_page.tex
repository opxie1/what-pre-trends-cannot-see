\smallskip

\noindent\textit{Data, material and code availability.} Every series used is a
public use file. The two constructed panels, the code that builds them, the
simulation scripts and the output file behind every number reported in the
paper are at
\url{https://github.com/opxie1/what-pre-trends-cannot-see}, at the tagged
release \texttt{v1.2}, which is immutable. Both panels rebuild offline from the
cached source files under \texttt{data/raw/}. The simulations are written in
Python and need version 3.11 or later with \texttt{numpy}, \texttt{scipy} and
\texttt{pandas}. They draw pseudorandom numbers from the NumPy PCG64 generator,
seeded once per replication by the CRC-32 checksum of a string naming the design
cell and the replication index, so that any cell can be regenerated on its own.
Producing every output file cited in the paper takes $61.2$ minutes in total.
